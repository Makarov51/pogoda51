# RSS фактической погоды: Мурманск, ВМО 22113

Проект получает реальные наземные SYNOP-сообщения станции 22113 из OGIMET и формирует RSS 2.0. Это наблюдения, не прогноз.

## Что будет в ленте
- дата и время наблюдения (UTC и местное время Мурманска);
- температура воздуха, если она передана в SYNOP;
- точка росы, ветер и давление, если соответствующие группы есть;
- исходное SYNOP-сообщение для проверки.

## Установка (бесплатно через GitHub Pages)

1. Создайте репозиторий на https://github.com/new (например, `murmansk-synop-rss`).
2. Загрузите в него содержимое этого ZIP-архива, включая скрытую папку `.github`.
3. Откройте **Settings → Actions → General → Workflow permissions**, выберите **Read and write permissions** и сохраните.
4. Откройте **Settings → Pages**. В разделе Build and deployment выберите **Deploy from a branch**, ветка `main`, папка `/docs`, нажмите Save.
5. Откройте **Actions → Update Murmansk RSS → Run workflow**, запустите вручную один раз. Далее workflow будет запускаться каждый час.
6. После первого успешного запуска RSS будет доступен по адресу:
   `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/feed.xml`

Подстановка: вместо `ВАШ-ЛОГИН` — ваш логин GitHub, вместо `ИМЯ-РЕПОЗИТОРИЯ` — имя репозитория. Не публикуйте URL до первого успешного запуска.

## Проверка источника
Исходный endpoint OGIMET:
https://www.ogimet.com/cgi-bin/getsynop?block=22113&begin=YYYYMMDDHHMM&end=YYYYMMDDHHMM&header=yes

Время в параметрах запроса — UTC. OGIMET может задерживать данные или временно не отдавать их; лента сохраняет предыдущую версию, если загрузка завершилась ошибкой. Запрашивается только последняя часть архива, с небольшим запасом, чтобы обновление не требовало больших запросов.

## Важные ограничения
- Параметры SYNOP декодируются частично: в ленту попадают только значения, которые можно уверенно извлечь из стандартных групп сообщения.
- Отсутствующие данные не заменяются нулями и не дополняются прогнозом.
- GitHub Actions не гарантирует запуск ровно в заданную минуту.
- Не используйте слишком частые запросы к OGIMET; здесь задан запуск раз в час.
